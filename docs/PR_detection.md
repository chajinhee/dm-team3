# [이상 탐지] PCA·K-means v6 코드와 성능 비교 추가

정상 운전 자료를 확대하고 시계열 조건부 잔차를 사용하는 PCA 탐지 결과를, main의 공통 모듈 위에서 재실행할 수 있도록 추가했습니다. 기존 원본 실행과 구별되는 개선 버전입니다.

- common.config와 common.preprocess를 사용하는 detection/ 모듈, 개발·최종 실행 스크립트, 검사 및 그래프를 추가했습니다.
- 설정은 train1 및 test1에서 정하고, train2 추가 정상 적합 후 고정 분위수로 test2와 train4를 평가합니다.
- 원본 대비 PCA의 test2 F1 .423→.557, 사건 검출 13→21/38입니다. 정밀도 .779→.767, 오경보 시간 11.24→18.10초/h입니다.
- 최신 K-means는 F1 .338→.158 및 오경보 지속시간 증가가 있어 비교 결과로 보고하고 최종 경보는 PCA를 채택했습니다.
- test2는 이전 실험에서도 사용한 후속 비교 데이터입니다.
- 파일별 AI 지원과 팀원 검토 기록 양식은 docs/AI_USE_detection.md에 있습니다.

실행 방법은 docs/DETECTION_README.md, 로컬 검증 상세는 results/detection/verification.json에 있습니다. 동결 개발 설정, 최종 지표, 사건표 및 PR 좌표를 분리 전 결과와 대조했습니다.
